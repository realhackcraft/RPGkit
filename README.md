# RPGKit

This is RPGKit, an RPG game development toolkit / game engine.

This project is in early development, so expect bugs. Please report them when
you find one.

## Using

You can use this toolkit by adding it as a dependency in your project. You can
use Maven, Gradle to do so, or even just adding the jar to your classpath.

## Testing

To test run the sample program run:

```sh
./gradlew sampleTest

```

Or on Windows,

```sh
gradlew.bat sampleTest
```
